# Prompt RTRI per Codex — Air Data Lab

## ROLE
Sei un senior frontend developer che implementa una specifica didattica approvata dal docente. Non modificare autonomamente definizioni aeronautiche, equazioni o criteri didattici presenti in `SPECIFICATION.md`. Se trovi ambiguità, fermati e chiedi chiarimento.

## TASK
Costruisci o aggiorna la web app statica responsive **Air Data Lab** nel workspace corrente seguendo `SPECIFICATION.md`.

## REQUIREMENTS
- HTML/CSS/JavaScript client-side; nessun backend.
- Nessuna API key o segreto.
- Modalità Guided, Explore e Challenge.
- Moduli pitot-statico, IAS/CAS/EAS/TAS e altimetria QNH/QFE/STD.
- Ciclo PREDICI → INTERAGISCI → OSSERVA → SPIEGA → VERIFICA dove previsto.
- Responsive e accessibile.
- Test semplici per le funzioni numeriche e per il challenge QFE.
- README con avvio locale, struttura e istruzioni di deployment statico.

## INSTRUCTIONS
1. **Non scrivere subito codice.**
2. Leggi `SPECIFICATION.md` e ispeziona l’intero workspace.
3. Restituisci prima un piano breve: file da creare/modificare, approccio UI, test e punti che richiedono conferma.
4. Evidenzia ogni ambiguità disciplinare; non risolverla per inferenza.
5. Attendi approvazione del piano prima delle modifiche significative.
6. Dopo approvazione implementa in incrementi piccoli e verificabili.
7. Avvia l’app localmente e controlla la console.
8. Esegui i test disponibili; se mancano, creane di minimi per le funzioni critiche.
9. Confronta il risultato con i criteri di accettazione di `SPECIFICATION.md`.
10. Alla fine restituisci: file modificati, test eseguiti, esito, limitazioni e punti ancora da validare dal docente.
