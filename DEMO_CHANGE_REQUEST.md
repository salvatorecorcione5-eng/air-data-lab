# Demo live — richiesta incrementale

Aggiungi alla modalità **Challenge / Altimetria** uno scenario QFE:

- aeroporto con elevazione 2,000 ft MSL;
- prima della soluzione chiedi: “Quale setting deve essere selezionato affinché l’altimetro legga 0 ft sulla pista?”;
- lo studente sceglie QNH, QFE o STD;
- il feedback viene mostrato soltanto dopo la scelta;
- con QFE corretto l’indicazione a terra deve essere 0 ft rispetto al datum aerodromico;
- il feedback deve spiegare esplicitamente la differenza tra **height** e **altitude**;
- aggiungi/aggiorna un test per questo scenario.

Prima di modificare i file, proponi il piano e indica quali file toccherai.
