# Validation checklist — Air Data Lab

## Gate disciplinare
- [ ] Definizioni QNH/QFE/STD validate dal docente.
- [ ] Relazioni pitot-statiche validate.
- [ ] Catena IAS/CAS/EAS/TAS coerente con il materiale del corso.
- [ ] Casi non-standard non presentati in modo fuorviante.

## Gate didattico
- [ ] Risposta dello studente prima del feedback negli esercizi.
- [ ] Lo studente deve prendere almeno una decisione significativa.
- [ ] Feedback spiega il principio, non solo “corretto/errato”.
- [ ] Modalità Cockpit/Teoria/Esercizi hanno ruoli distinti.

## Gate software
- [ ] Nessun errore console nei percorsi nominali.
- [ ] Funziona su desktop e smartphone.
- [ ] Controlli con range e unità espliciti.
- [ ] Test critici superati.

## Gate deployment
- [ ] Nessuna API key o segreto nel client.
- [ ] Nessun dato personale/sensibile nel repository.
- [ ] Versione/tag identificato.
- [ ] URL pubblico verificato.
- [ ] QR punta all’URL previsto.
